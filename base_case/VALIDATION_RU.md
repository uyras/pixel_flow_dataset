# Проверки базового кейса

Проверено 28 октября 2026 года в OpenFOAM Foundation 14, Build `14-a4867fc914c1`. Использован официальный пакет Ubuntu 24.04 `openfoam14_20261008_amd64.deb`; SHA256 пакета: `99fe066c827f2834474692d63c2a3c45ef094a7253d115841635ba35acbb0067`. Запуски последовательные, один процесс, двойная точность.

## Исходный вариант U_in 1 м/с

Сетка с полным телом L = 4, N = 60 успешно создана `blockMesh` и прошла `checkMesh -allTopology -allGeometry` с результатом `Mesh OK.`.

- 25 200 жидкостных ячеек, 20 блоков.
- Границы: (−1, −1, 0) — (3, 1, 0.01) м.
- Один слой по z; расчётная размерность — 2D.
- Объём жидкости 0.07 м³.
- Максимальная неортогональность 0; максимальный skewness около 2.13e-13.

Расчёт прошёл 20 000 итераций без фатальной ошибки, но **не достиг заданной сходимости**. Конечные начальные нормированные невязки:

| Поле | Получено | Требование |
|---|---:|---:|
| p | 7.8916e-2 | < 1e-5 |
| Ux | 1.1934e-2 | < 1e-6 |
| Uy | 1.7126e-2 | < 1e-6 |

Сохранён ровно один каталог результата — `20000`; промежуточных снимков полей нет. Машинный статус: `validation/default_U1_status.json`. Финальные поля этого несошедшегося расчёта не включены в архив базового кейса.

Этот результат относится к приведённым схеме, релаксации, сетке и начальным полям. Он не доказывает математического отсутствия стационарного решения. Заданные ламинарность, стационарность, скорость и вязкость не изменялись ради достижения сходимости.

## Контрольный вариант с малым числом Рейнольдса

При U_in = 0.0001 м/с, том же полном теле и той же сетке расчёт сошёлся на итерации 1445:

| Поле | Начальная невязка последней итерации |
|---|---:|
| p | 3.05447e-7 |
| Ux | 5.33143e-7 |
| Uy | 9.97663e-7 |

Контроллер напечатал `SIMPLE solution converged in 1445 iterations`. Сохранён ровно один каталог результата — `1445`, несмотря на лимит 5000 итераций. Таким образом, проверены ранняя остановка и принудительная запись последнего состояния без промежуточных снимков. Статус: `validation/low_re_status.json`.

По записанным 120 значениям скорости на входе проверен параболический профиль: максимальное отличие от U_in*(1−y²) в центрах граней около 4.45e-17 м/с. Дискретная средняя скорость 6.66689814815e-5 м/с; небольшое отличие от непрерывного среднего 6.66666666667e-5 связано с дискретизацией по центрам граней.
